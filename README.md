# 🍕 Pizza Sales Analysis — Power BI Dashboard

An interactive **Pizza Sales Analysis Dashboard** built using **Microsoft Power BI** to analyze sales performance, customer ordering patterns, pizza categories, sizes, and best/worst-selling pizzas.

## 📊 Project Overview

This project analyzes pizza sales data to identify important business insights such as total revenue, total orders, pizzas sold, average order value, and sales performance across different categories and pizza sizes.

The dashboard contains interactive filters and visualizations that allow users to explore the data easily.

## 🛠️ Tools & Technologies

* Microsoft Power BI
* Power Query
* DAX
* Data Cleaning & Transformation
* Data Visualization

## 📌 Key KPIs

* **Total Revenue:** 817.86K
* **Average Order Value:** 38.31
* **Total Orders:** 21K
* **Total Pizzas Sold:** 50K

## 📈 Dashboard Features

### 🏠 Home Dashboard

The Home page includes:

* Total Revenue
* Average Order Value
* Total Orders
* Total Pizzas Sold
* Average Pizzas per Order
* Daily Trend for Total Orders
* Monthly Trend for Total Orders
* Sales by Pizza Category
* Sales by Pizza Size
* Total Pizzas Sold by Category
* Pizza Category filter
* Date range filter

### 🏆 Best / Worst Sellers

The second page analyzes:

**Best Sellers**

* Top 5 Pizzas by Revenue
* Top 5 Pizzas by Quantity
* Top 5 Pizzas by Total Orders

**Worst Sellers**

* Bottom 5 Pizzas by Revenue
* Bottom 5 Pizzas by Quantity
* Bottom 5 Pizzas by Total Orders

## 🔍 Key Insights

* The **Classic** pizza category contributes the highest number of pizzas sold.
* Large-size pizzas contribute significantly to overall sales.
* The dashboard helps identify the top-performing and lowest-performing pizzas.
* Friday shows strong order activity compared with several other days.
* Monthly trends help identify changes in order volume throughout the year.
